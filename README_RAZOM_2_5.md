# RAZOM 2.5 — пакет додаткових функцій

Цей архів — **оновлення наявного RAZOM 2.4**, а не повна заміна застосунку.
Під час встановлення **не замінюються** ваші поточні `main.py`, `telegram_bot.py`, `render.yaml`, `.env` та база даних; скрипт лише додає реєстрацію нового API і вставляє розділи у вебінтерфейс.

## Додані функції

1. **Пошук можливих дублікатів** — `/admin/duplicates`: збіги міста/категорії та схожі описи, зіставлення доступне лише адміністратору. Нічого не видаляє та не блокує автоматично.
2. **Інтелектуальний підбір ресурсів** — `/smart-matches`: ранжування пропозицій волонтера за критичністю заявки, категорією та кількістю доступних ресурсів. Підбір обмежений власним інвентарем волонтера та затвердженими заявками.
3. **Прогноз потреб** — `/admin/forecast`: орієнтовна оцінка на наступні 7 днів за двома попередніми тижнями. Якщо по категорії менше 10 заявок або історія коротша за 14 днів, результат не вигадується — показується «Недостатньо даних». Це проста статистична модель, а не перевірена модель машинного навчання.
4. **Карта та логістика** — `/admin/geography`, `/logistics/matches`: міські зведення для адміністратора, відповідності між ресурсами та заявками для волонтера, приблизна відстань по прямій і посилання на зовнішнє прокладання маршруту в Google Maps. Показуються **центри відомих міст, не адреси людей**. Невідомі містечка не наносяться на карту автоматично. Для мапи потрібне підключення до інтернету (Leaflet/OpenStreetMap).

## Встановлення у свій актуальний репозиторій

1. Зробіть резервну копію свого репозиторію / зафіксуйте зміни в Git.
2. Розпакуйте цей архів **у кореневу папку вашої актуальної копії RAZOM на комп'ютері** — там, де вже лежить `main.py`. Не замінюйте `main.py` старою версією з іншого архіву.
3. У терміналі VS Code виконайте:

```powershell
python apply_razom_upgrade.py
python -m pytest -q
```

4. Запустіть сайт локально й перевірте в кабінеті адміністратора та волонтера. Тільки після перевірки комітьте й пуште на GitHub.

Інсталятор можна запускати повторно: він не повинен подвоювати зміни.

## Межі функціональності

- Це **дослідний модуль** для демонстраційної системи. Не використовуйте його прогнозування чи маршрути для прийняття рішень щодо термінової допомоги без людської перевірки.
- Позначки міст — наближені координати. Відстані по прямій відрізняються від дорожніх; час у дорозі й стан доріг не розраховуються.
- Пошук дублікатів може давати хибні збіги; адміністратор має перевірити їх вручну.
- Міста поки задані офлайн-словником України у `razom_features.py`, і їх можна доповнювати.
- Збережені дані/таблиці не змінюються. Доступ до адміністративних звітів обмежений роллю.

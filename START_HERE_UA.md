# RAZOM 2.4 — Gemini AI + Telegram + дві черги

## Найпростіший запуск на Windows

1. Розпакуйте ZIP в **нову** папку. Старий проєкт і його базу даних не видаляйте.
2. Встановіть Python 3.11+ з python.org (під час встановлення увімкніть Add Python to PATH).
3. Двічі клацніть `SETUP_WINDOWS.bat`. Скрипт створить `.venv`, встановить бібліотеки і **лише якщо `.env` ще немає**, створить його з випадковим `JWT_SECRET`.
4. Відкрийте `.env` у VS Code/Блокноті, заповніть:
   - `GEMINI_API_KEY=...` — ключ Google Gemini, **не публікуйте**;
   - `GEMINI_MODEL=gemini-2.5-flash` — модель;
   - `TELEGRAM_BOT_TOKEN=...` — токен бота від BotFather, **не публікуйте**;
   - `TELEGRAM_BOT_USERNAME=...` — ім’я бота без `@`;
   - `SITE_URL=https://ВАШ-РЕАЛЬНИЙ-САЙТ` — публічна HTTPS-адреса, на якій працює саме цей сервер і база даних.
5. Запустіть `START_WINDOWS.bat` і відкрийте `http://127.0.0.1:8000`.
6. Створіть адміністратора командою `.venv\Scripts\python.exe create_admin.py` у терміналі в цій папці. Пароль вводиться лише на вашому комп’ютері.
7. Увійдіть адміністратором, створіть тестову заявку **з вигаданими даними**. У кабінеті підключіть Telegram через кнопку «Підключити Telegram» і натисніть Start у боті. Підтверджуйте волонтерів у кабінеті адміністратора.
8. Перевірте вкладки «За важливістю» та «За часом», джерело пріоритету Gemini AI / локальні правила, Telegram-повідомлення і перехід за посиланням.

## Важливі нюанси

- **Звичайне локальне тестування**: `SITE_URL=http://127.0.0.1:8000` дасть у повідомленні посилання, яке працює тільки на **вашому комп’ютері**. Telegram-кнопка з URL доступна тільки для HTTPS; на локальному HTTP бот відправить текстове посилання. Для посилань, доступних усім, потрібно розгорнути саме цей сервер на хостингу й поставити реальну HTTPS-адресу.
- Бот надсилає сповіщення **лише тим адміністраторам і підтвердженим волонтерам, які підключили Telegram у своєму акаунті**. Бот не може написати людині, яка не натиснула Start.
- Адміністратори отримують усі нові заявки. Заявки зареєстрованих заявників одразу надходять підтвердженим волонтерам, крім категорії «може зачекати» (її видно в черзі та команді `/queue`). Гостьові заявки спочатку перевіряє адміністратор, після чого волонтери отримують сповіщення.
- Два списки — це **два способи сортування тих самих відкритих заявок**, а не дві незалежні бази. Відкрийте кабінет адміністратора або підтвердженого волонтера.
- Gemini працює тільки з новими заявками, створеними під час поточного запуску сервера; після перезапуску раніше створені заявки оцінюються локальними правилами. Результат Gemini кешується в пам’яті на 24 години. Для постійного зберігання результатів потрібна окрема міграція БД.
- Gemini може помилятися. Пріоритет — підказка для людини, а не автоматичне рішення щодо життя, медицини чи евакуації. Перед Gemini маскуються типові контакти, але маскування не гарантоване: не використовуйте реальні персональні/медичні дані в демонстрації. Перевірте умови обробки даних безкоштовного Gemini API.
- Запускайте **лише один** екземпляр Telegram polling із цим токеном: якщо старий сервер/бот уже працює, для локальних тестів використайте іншого тестового бота. Не запускайте uvicorn з кількома workers для одного polling-бота.
- Не переносіть стару SQLite-базу навмання. Для збереження онлайн-заявок і акаунтів треба з’ясувати, яка БД і який хостинг використовуються, зробити резервну копію та перевірити схему.
- Файли `.env` та `volunteer.db` не включені до ZIP, щоб не розкривати секрети та особисті дані.

## Ручний запуск (macOS/Linux/Windows)

`python -m venv .venv` → активуйте середовище → `python -m pip install -r requirements.txt` → створіть `.env` за `.env.example` і згенеруйте `JWT_SECRET` (мінімум 32 символи) → `python create_admin.py` → `python -m uvicorn main:app --port 8000`.

## Що робити зі старим RAZOM

**Не видаляйте старі папки, `.env` або бази даних.** Тримайте нову версію окремо, тестуйте з окремою локальною БД. Лише після перевірки та резервного копіювання оновлюйте хостинг. Старий сайт залишається робочим до свідомого перемикання.
